A collection of Python mini projects for learning, practice, problem solving, and portfolio development.

## Projects

### 1. Random Joke Generator

A Python-based Random Joke Generator application that retrieves and
displays random jokes.

**Technologies:**
- Python
- REST API
- JSON
- Tkinter
- PyInstaller

### 2. Retail Sales Analytics with NumPy

A small data analytics project that demonstrates how Python and NumPy can be used to clean, validate, transform, and analyze messy retail sales data.

**Technologies:**

- Python
- NumPy
- Power BI
